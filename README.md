# RYVEN STUDIOS — 3D Web Developer Portfolio

Portofolio pribadi Ryven Akmal A. (RYVEN STUDIOS), Web Developer dari Pacitan.

## Fitur
- Karakter manusia 3D interaktif bawaan template.
- Animasi dan interaksi berbasis Three.js / React Three Fiber.
- Animasi scroll dengan GSAP.
- Bagian profil, keahlian, proyek, perjalanan belajar, dan kontak.
- Responsif untuk perangkat desktop dan mobile.

## Teknologi
React, TypeScript, Vite, Three.js, React Three Fiber, GSAP, dan CSS.

## Menjalankan proyek
```bash
npm install
npm run dev
```

## Build produksi
```bash
npm run build
npm run preview
```
